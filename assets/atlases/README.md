# Block atlases

Runtime texture atlases for voxel blocks. This folder is staged next to the
desktop executable and merged into the Switch NRO's romfs, so the game loads
tiles from:

- desktop: `<exe dir>/assets/atlases/`
- Switch: `romfs:/atlases/` (inside the `.nro`, **not** the SD card)

## `blocks.png`

A 4×1 grid of 16×16 tiles, in this order:

| index | tile        |
|-------|-------------|
| 0     | grass top   |
| 1     | grass side  |
| 2     | dirt        |
| 3     | stone       |

The layout constants live in `src/world/BlockAtlasLayout.hpp`; each block's six
faces are mapped to a tile in `src/world/Block.cpp`.

This PNG is our own work, generated by the built-in procedural atlas
(`src/render/BlockAtlas.cpp`) and covered by the project licence. Regenerate it
with:

```
voxelgame --export-atlas   # writes assets/atlases/blocks.png, run from the repo root
```

Replace it with hand-painted art of the same size and tile order to change the
look — no code change required. To use a different grid, update
`BlockAtlasLayout.hpp` (tile size, columns, rows) and the per-face tile indices.
