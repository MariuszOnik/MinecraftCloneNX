# Block atlases

Runtime texture atlases for voxel blocks. Resolved by `src/platform/Assets.cpp`:

- desktop: `<exe dir>/assets/atlases/`
- Switch: `sdmc:/switch/voxelgame/assets/atlases/` first, then `romfs:/assets/atlases/`
  (bundled in the `.nro`)

An atlas is a pair: an image plus a `.json` descriptor that tells the engine the
grid and which tile each block face uses. The engine loads `atlases/blocks.json`.

## `blocks.json`

```json
{
  "texture": "blocks.png",
  "atlasSize": [64, 16],          // atlas image size in pixels
  "tileSize": 16,                 // square tile edge; must divide atlasSize
  "tiles": {                      // name -> [column, row] in the grid
    "grass_top": [0, 0], "grass_side": [1, 0], "dirt": [2, 0], "stone": [3, 0]
  },
  "blocks": {                     // block name (from the registry) -> faces
    "grass": { "top": "grass_top", "bottom": "dirt", "sides": "grass_side" },
    "dirt": "dirt",               // a bare string sets all six faces
    "stone": "stone"
  }
}
```

`columns` and `rows` are derived from `atlasSize / tileSize`. Tile index is
`row * columns + column`. Face slots: `top` = +Y, `bottom` = -Y, `sides` = the
four horizontal faces. Blocks not listed keep the compiled defaults from
`src/world/Block.cpp`.

If the descriptor is missing or invalid the engine logs a warning and uses those
compiled defaults; if the image is missing it generates one procedurally
(`src/render/BlockAtlas.cpp`) and resets to the default grid.

## `blocks.png`

Our own work, generated by the procedural atlas and covered by the project
licence. Regenerate with `voxelgame --export-atlas` (run from the repo root).
Replace it with art matching `blocks.json` — no code change needed. For a
different atlas, ship a new image + descriptor; only the grid and names in the
JSON change.
